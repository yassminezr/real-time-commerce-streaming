# Real-Time Commerce Streaming Platform

Event-driven e-commerce data engineering project using
Apache Kafka, Spark Structured Streaming, Cassandra,
Python and Docker.

## Architecture

Python Producers → Kafka → Spark Structured Streaming → Cassandra

## Features (Planned)

- Multi-source event ingestion
- Event validation and deduplication
- Event-time processing and watermarking
- Stream-stream joins
- Order state reconstruction
- Cassandra persistence
- Checkpointing and reliability testing
